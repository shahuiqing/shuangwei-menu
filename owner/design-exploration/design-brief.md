# 老板端全面重构 · 设计说明（方向探索）

> 方法论：oil-ui。任务：全面重构「炙·双味居」老板管理端的页面设计。
> 本文件是方向探索阶段的产出，方向待用户选定后再落地实现。

## 一、认品类，拆标杆

**品类**：餐饮经营后台 / 老板管理端。核心用户是店主（老板），每天高频查看经营数据，
主任务是「看营收、看成本、看毛利、看问题」，次要任务是「改库存、走订单状态、补录、采购」。

**标杆**（风格最鲜明、完成度最高）：

1. **Stripe Dashboard** — 经营数据看板的事实标准。
   - KPI 用「大数字 + 环比箭头」放在最顶上，数字是第一主角。
   - 图表克制，网格线极淡，只用一种强调色；颜色让位给数据本身。
   - 卡片几乎无阴影、用极细描边分隔，靠间距建立层级，不靠立体。
   - 为什么：经营者要在一秒内读懂数字，视觉不能抢戏。

2. **Toast / Square 商家后台** — 餐饮经营后台。
   - 销售/成本/劳工分成清晰的「日报」结构，顶部是当天的营收大数。
   - 数据密度高，表格是主力，等宽数字对齐到列。
   - 状态用统一的小圆点 + 短标签（不是多彩色块）。
   - 为什么：餐饮老板下班后要看「今天赚了多少、花了多少」，日报结构最贴使用场景。

3. **Linear** — 工具类产品精致度的上限（借它的完成度，不借它的视觉）。
   - 控件圆角、描边、阴影统一成一套，键盘/动效手感一致。
   - 信息密度中等，留白有纪律。
   - 为什么：精致感来自「一套语言贯彻到底」，而不是堆装饰。

**决定留 / 换**：

| 标杆要素                | 留还是换   | 理由                                     |
| ----------------------- | ---------- | ---------------------------------------- |
| KPI 大数字 + 环比置顶   | 留（基线） | 经营者第一眼要数字，沿用                 |
| 数据密度中等、表格主力  | 留（基线） | 后台用户习惯                             |
| 状态用统一小圆点+短标签 | 留         | 减少认知负担                             |
| 一张卡片网格铺满首页    | 换         | 这是后台「套路」，本轮至少一个方向要打破 |
| 暗色 + 单一品牌橙       | 换/重组    | 现有系统已固化，重构需要重新定色彩身份   |

## 二、先定调性

从「高端炭烤 + 火锅」「老板是主角」「打烊后复盘」推出，证据指向：**不是喧闹的网红风，也不是冰冷的企业后台**，
而是一个「有温度的、属于一家具体餐厅的经营工具」。

五个刻度（作为本轮方向的共同约束，再在构图上拉开差异）：

| 刻度   | 取值     | 依据                          |
| ------ | -------- | ----------------------------- |
| 能量   | 中偏安静 | 打烊后复盘，不是营业高峰      |
| 完成度 | 精致     | 高端餐厅，细节要到位          |
| 密度   | 中       | 数字要多但不堆砌，留出呼吸    |
| 分量   | 中偏重   | 营收/毛利是重信息，字要站得住 |
| 严肃度 | 中偏庄重 | 老板在算账，不轻浮            |

## 三、三个方向卡

> 每个方向用不同的生成引擎、不同的色彩身份、不同的首屏骨架。
> 差异检验：首屏骨架（卡片网格 / 流水单 / 留白账本）互不相同；色彩身份（炭火橙 / 纸墨冷青 / 宣纸暖白墨）互不相同；
> 至少两个打破「侧栏+卡片网格」后台套路。

### 方向 A ·「炭火账房」

- **生成引擎**：材质 × 环境 ——「炭火余烬 × 深夜打烊后的账房」。
- **北极星**：像坐在打烊后还留着炭火余温的柜台前，借着一点光翻看今天的流水。
- **调性**：能量中偏高（暖橙微光）、完成度精致、密度疏、分量重、严肃度中。
- **色彩身份**：深炭底 `#0b0a09` + 炭火橙 `#f97316` / 余烬 `#fb923c` + 暗金 `#f59e0b`；卡片比底色浅一层的暖黑 `#171410`，描边带一点暖色。
- **首屏骨架**：营收大卡（炭火渐变 + 微光）+ KPI 网格（延续基线，但质感升级为「烧红的金属边」）。
- **控件语法**：圆角 12px，主按钮炭火渐变、按下像余烬「焖下去」变暗；卡片描边带 1px 暖色微光。
- **记忆点**：营收数字打开时像炭火复燃一样从暗到亮，数字本身是唯一发光体。
- **放弃**：纯灰白的冷调、多余的氛围光、彩色的分类色块。

### 方向 B ·「明档流水」

- **生成引擎**：一个具体场景 ——「凌晨后厨明档，摊开的当日流水单」。
- **北极星**：像翻一张张当日流水单，数字即全部，没有一句废话。
- **调性**：能量安静、完成度精致（对齐严格）、密度密、分量轻、严肃度高。
- **色彩身份**：纸面黑白灰 `#0c0d0f`/`#17181c` + 一个冷青 `#38bdf8`（或墨青）作为唯一强调；等宽数字承担识别。
- **首屏骨架**：打破卡片网格 → 「收银条式」营收汇总 + 高密度流水表；KPI 排成一行账目，像票据上的小计。
- **控件语法**：直角或极小圆角（2–4px），细描边，行高紧，等宽数字 tabular 对齐到列。
- **记忆点**：营收总汇用等宽大数字排成一张「收银条」，扫码结账那一刻的即视感。
- **放弃**：卡片阴影、彩色 KPI 图标底、圆润的大圆角。

### 方向 C ·「东家账本」

- **生成引擎**：一场文化语法 ——「新中式宣纸账本」，与「双味居」的中文店名/高端定位真实相关。
- **北极星**：像翻开一本毛笔竖排的老账本，安静、克制、留白，数字一笔一划。
- **调性**：能量安静、完成度精致、密度疏、分量轻、严肃度庄重。
- **色彩身份**：宣纸暖白 `#f5f1e8` 底 + 墨色 `#1a1611` + 朱砂 `#c0392b` 一个强调色；宋体标题承担识别。
- **首屏骨架**：打破暗色后台 → 浅色大留白，竖排标题「今日结」，宋体大字营收，朱砂印章式标记。
- **控件语法**：圆角 8px，描边用墨色低透明，主按钮朱砂色；选中态像盖一方小印。
- **记忆点**：营收用宋体大字 + 右下角一枚朱砂「结」印，像账本盖了章。
- **放弃**：暗色背景、霓虹/发光、现代无衬线的冷感。

## 四、首屏小样范围

每个方向的小样只做「营业看板」首屏 + 最能体现方向的一个区块，表达骨架、字体、色彩、控件手感；
真实数据用店主熟悉的营业数字（营业额 / 订单 / 客单价 / 毛利 / 成本率 / 分类占比 / 本周改善）。
选定方向后再延展到其余页面并落地代码。
